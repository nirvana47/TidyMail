<objective>
Restore the mock-aligned cleanup hierarchy after the tracer: compact category headers with split metrics, professional table-like sender rows, right-aligned quiet controls, and rounder accessible buttons (D-15, D-16, D-17, D-18, D-19), plus category-management affordances (`Move selected`, `Create category`, `Change type`) and visible `User generated` tags while keeping exact row-key staging and account-owned category boundaries intact (D-20, D-21, D-22, D-24).
</objective>

<threat_model>
ASVS level: 1. Block on unresolved high severity.
- T-16-06 custom category authorization: user-generated categories must be account-owned and resolved through the authenticated owner key; no cross-user/global learning rules.
- T-16-07 HTML/script injection: user-created category names must be sanitized, stored/displayed as plain text, and escaped in Thymeleaf.
- T-16-08 exact action scope confusion: category header metrics, selected checkbox counts, and estimated sizes never become action scopes.
- T-16-09 protected sender bypass: row-density and control-copy changes must keep protected sender labels and disabled action controls.
- T-16-10 destructive UI confusion: Archive/Delete/Mark as Read labels may change with Settings, but Delete still requires Trash recovery acknowledgement before staging.
</threat_model>
