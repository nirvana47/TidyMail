  <action>
Create `PublicAddressPolicy` as an explicit allow-global policy, not a wrapper around
only `InetAddress.isSiteLocalAddress()`. Reject IPv4 unspecified/0/8, loopback,
RFC1918, link-local/cloud metadata, CGNAT, benchmark, documentation, multicast,
reserved, future-use, and alternate/mapped representations. Reject IPv6 unspecified,
loopback, link-local, unique-local/site-local, multicast, documentation/reserved,
discard-only, benchmarking, ORCHID, 6to4, Teredo/transition, and all IPv4-mapped or
IPv4-compatible forms. Base the table on the checked-in IANA IPv4/IPv6 special-purpose
registry categories and default-deny any non-global-unicast category; include named
boundary tests for every prefix and adjacent public controls. Keep all IP literals
already blocked at URI parsing.

Before DNS, require a canonical STD3 ASCII multi-label hostname and reject empty or
single-label names, `localhost` and its subdomains, `.local`, `.localdomain`,
`.internal`, `.home.arpa`, invalid/ambiguous punycode, terminal-dot ambiguity after
normalization, and overlong labels/hostnames. DNS results remain authoritative for
the final all-address public check even for an otherwise acceptable hostname.

Create an injected `DestinationResolver` that resolves A/AAAA once under a two-second
DNS deadline using a bounded executor/future boundary whose late result can never be
used after timeout. Canonicalize/deduplicate answers, reject zero or more than eight
answers, and reject the complete set if any member is non-global. Return immutable
`ResolvedDestination(asciiHostname, addresses)` with no DNS detail in public errors.
No fallback resolver or second lookup is allowed after resolution; executor capacity
and shutdown/cancellation behavior must prevent timed-out lookups from accumulating.

Add immutable validated configuration defaults:
DNS 2s, connect 3s, TLS handshake 3s, response-header 5s, total 10s, maximum 8 DNS
answers, maximum 8192 response discard bytes, redirect hops 0, automatic retries 0.
Validate positive bounded ranges at startup. Do not add an environment switch that
allows localhost/private destinations.

Test every prohibited IPv4/IPv6 category and prefix boundary, public controls,
special-use hostname class, empty/excess answers, mixed public/private sets, IDN
hostname handoff, hard deadline/late answer behavior, and mapped/transition cases.
  </action>
  <verify>JAVA_HOME=$(/usr/libexec/java_home -v 21) mvn -q -Dtest=Phase11UnsubscribeSecurityTest test</verify>
  <acceptance_criteria>
    - All address classes listed under QUAL-01 in `11-VALIDATION.md` have named rejection tests.
    - Special-use, single-label, and malformed hostnames fail before DNS or connector invocation.
    - One non-global answer rejects an otherwise public set.
    - Resolver returns no mutable address collection and is invoked once per attempt.
    - Production configuration has finite validated limits and no private-network bypass.
  </acceptance_criteria>
  <done>Only a bounded all-global DNS answer set can reach the connector boundary.</done>
