<objective>
Turn the persistence/provider tracer into a durable progressive sync engine: fast bootstrap, starvation-proof freshness, bounded backfill units, and safe expired-history rescan. Preserve server ownership after OAuth and route only new accounts to Activity while returning accounts keep normal cleanup navigation.
</objective>

<threat_model>
ASVS L1; block high severity. Account isolation: queued work contains account ID plus lane and re-resolves the owned account; leases are keyed by account/lane. Token/error leakage: workers log safe support codes only and rely on managed credentials. Destructive refresh failure: REAUTH_REQUIRED halts provider work without deleting or sweeping. Cursor tampering/replay: durable CAS leases, cursor-kind validation, atomic commits, and replay tests prevent client/process-local authority. Provider-body leakage: workers consume only MailboxSyncProvider metadata records. CSRF: manual requestSync remains authenticated POST with CSRF and owned account validation. Stale-rescan deletion: H1 installation requires bounded repair; generation sweep is guarded against post-start freshness writes and never runs on partial traversal.
</threat_model>
