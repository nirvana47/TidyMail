# Phase 1 — Project Scaffold (pom.xml + entrypoint)

**Rationale:** "You don't have a Java project until pom.xml exists. Maven is the source of truth for all dependencies."
**Effort:** Small
**Dependencies:** None
**Critical path:** First phase — must produce BUILD SUCCESS before Phase 2 can start.

## Goals
1. Valid Maven 3.9+ project with pom.xml using Spring Boot 3.5.16 parent POM
2. Standard Maven source tree (src/main/java, src/main/resources, src/test/java) populated
3. Executable entrypoint annotated with @SpringBootApplication compiles
4. `mvn -q package` produces BUILD SUCCESS and a runnable target/tidymail-0.1.0.jar
5. .gitignore matches Maven + Java + IntelliJ + Eclipse + VS Code + .env + Spring Boot defaults

## Tracer Task (verifiable end-to-end slice)
T1. **Build & package the empty Spring Boot app.**
   Input: pom.xml + InboxCleanerApplication.java
   Execution: `cd project_root && mvn -q clean package`
   Expected: Exit code 0, file `target/tidymail-0.1.0.jar` exists, jar is runnable (`java -jar target/tidymail-0.1.0.jar` starts on port 8080 with no 5xx startup errors in a 10-second smoke test).

## Decisions Made in This Phase
- Java 21 LTS + Maven + Spring Boot 3.5.16 (last 3.5 OSS release, stable)
- Package name: com.tidymail, artifactId tidymail, version 0.1.0 (semver)
- springboot3-dotenv 5.1.0 for .env file loading (paulschwarz, BOM import pattern)
- Lombok optional-provided scope (team can enable via IDE processors but not required)
- Flyway included but initially disabled via ddl-auto:update for local dev; production will use Flyway migrations (Phase 3+ concern)
- JPA open-in-view = FALSE (explicit, no lazy-loading surprises in Thymeleaf views)

## Risks
- R-1.1: Dependency version conflicts between Google HTTP client and Spring Boot managed Jackson. Mitigation: rely on Spring Boot BOM for Jackson; exclude Jackson from google-http-client-jackson2 if needed.
- R-1.2: maven-compiler-plugin needs explicit release=21 flag or some IDEs default to Java 17. Mitigation: configure both source/target and release properties in pom.xml properties.
- R-1.3: Spring Boot 3.5.16 was just released June 2026; mirror sync issues possible. Mitigation: fall back to 3.5.15 or 3.4.x if Maven Central errors.
